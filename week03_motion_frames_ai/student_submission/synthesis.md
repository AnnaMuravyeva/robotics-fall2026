# Technical synthesis

A robot motion program can be technically correct and still fail as a part of a sociotechnical system for various reasons. For example, a robot could follow the expected path through a hallway, but it might get in the way of people walking there or someone using a wheelchair. People may also not know where the robot is going to move next which could make them feel uncomfortable or unsafe. Testing the robot for accuracy is important, but it doesn't guarantee that it will work well in a shared space. To evaluate this issue, I would want to see how the robot does in a hallway with people in it and see how people are able to coexist with the robot. I would be interested in how easily people can move around it and how the robot responds when someone gets in its way.
